## Fonts

Manrope and Newsreader are stored as local Latin variable-font subsets in `src/app/fonts/` and loaded with `next/font/local`. The files came from the font assets generated by Next.js for these same Google Fonts families in an earlier project build. Keeping the subsets in the repository removes development-time dependence on `fonts.googleapis.com`.

- Manrope official distribution: `https://github.com/google/fonts/tree/main/ofl/manrope`
- Newsreader official distribution: `https://github.com/google/fonts/tree/main/ofl/newsreader`
- License for both families: SIL Open Font License 1.1, included in each official Google Fonts directory.

## Replacement guidance

Before presenting a concept as real client work, replace its demonstration image with an authorized client asset, update alt text, remove fictional names, add only verified claims, and update this file with source and usage permission.
